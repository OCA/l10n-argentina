This module provides the base infrastructure for AFIP (ARCA) web
services integration in Argentina.

It includes:

- Certificate management for AFIP authentication
- Connection handling to AFIP web services
- Token authentication (WSAA)
- Base models for web service operations

This is a dependency module for other AFIP-related modules like
electronic invoicing.
