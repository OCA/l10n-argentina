This module enables electronic invoicing for Argentina using AFIP (ARCA)
web services.

Features:

- Electronic invoice validation with AFIP
- Support for multiple document types (Factura A, B, C, etc.)
- CAE (Código de Autorización Electrónico) management
- Integration with Odoo's invoice workflow
- AFIP response handling and error management

Supported web services:

- wsfev1 - Factura Electrónica
- wsbfev1 - Bono Fiscal Electrónico
- wsfexv1 - Factura de Exportación Electrónica
